# Переоборудование TEVO-BW в установщик компонентов

Инженерный проект по переоборудованию 3D-принтера TEVO Black Widow в настольный станок для установки SMT-компонентов. В проект входят параметрические модели FreeCAD, конструкция питателя TBW-Feeder v3.0, инструкции по сборке, предварительные электрические схемы и ведомости материалов (BOM).

> **Состояние проекта:** прототипная конструкция. Проверки CAD и схемы не подтверждают безопасность или работоспособность собранного станка. Перед эксплуатацией проверьте совместимость с реальной рамой, проводку и защиту, пределы перемещения и работу питателя.

## Состав проекта

- Параметрическая модель станка для FreeCAD и скрипты построения.
- Механическая конструкция портала, головки, рабочего стола и приводов.
- Восьмипозиционный питатель с пошаговой подачей ленты и узлом снятия покровной плёнки.
- Предварительная архитектура питания 24 В, компьютер управления, камеры и контроллеры.
- Сборочные схемы, рендеры, отчёты и предварительные BOM.

## Сборка CAD

Установите FreeCAD 1.1. В PowerShell выполните:

```powershell
cd pnp
.\pnp.ps1 build
.\pnp.ps1 check
.\pnp.ps1 all
```

Проверка модели охватывает заданные положения в CAD, но не подтверждает геометрию реального принтера, электробезопасность или производительность. Для OpenPnP сейчас рекомендуется компьютер x86-64; Raspberry Pi описан как вспомогательный/экспериментальный вариант до проверки ARM64-сборки и работы камер.

Подробные исходные руководства и PDF-сборник пока на английском языке. Этот перевод — краткое описание и указатель по проекту.
